# Branch CI Implementation Plan

**Goal:** Build and test branch pushes and PRs, and require passing checks on main.

**Architecture:** One matrix workflow, a small checksum-pinned tool installer,
and GitHub branch protection configured after the workflow passes remotely.

**Tech stack:** GitHub Actions, Bash, let-go 1.13.0, lgx 0.3.2, Node.js.

## Implementation and validation

- [ ] Add `.github/workflows/ci.yml` with Linux and macOS jobs, read-only
  permissions, stable names, timeouts, and push/PR/manual triggers.
- [ ] Add `.github/scripts/install-tools.sh` to fetch and verify release binaries.
- [ ] Add contributor-facing CI instructions to README.
- [ ] Check shell syntax and workflow syntax; run the browser probe locally.
- [ ] Push the branch with the existing pre-push suite enabled and inspect both
  hosted jobs. Resolve failures before merging.
- [ ] Fast-forward main, verify its hosted checks, then enable strict required
  checks and PR-only merges, including administrators. Verify settings by API.

No public PR or comment is needed to bootstrap this already-authorized change.
